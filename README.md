# unit-1-oop-lab

## Getting Started

Welcome to the Object-Oriented Programming (OOP) lab. In this lab, you will find various problems designed to help you understand and apply OOP concepts by creating and working with classes.

### Instructions

1. Carefully read each problem statement.
2. Write the required classes and methods to meet the problem requirements.
3. Use the provided examples to test your classes and ensure they work correctly.
4. Once you have completed all the problems, review your code for accuracy and completeness.
5. Submit your completed work in Learn.

Make sure to complete all the class-based problems in this repository before submitting. Good luck, and have fun learning!
